# Bitblock, for an agent that has not seen it

Paste this whole page to an agent working in this repository.

## What this is

Bitblock is a deterministic bit-world simulator with a content-addressed history
protocol. It is ~52,000 lines of Rust across 33 modules, ~5,900 lines of
protocol prose, a 1,112-family metric registry, 22 independent Python vector
suites, and a Lean proof capsule.

Do not scan it. Query it.

## The four commands you need

```bash
python tools/bbgraph.py ask "canonical framebuffer bytes"
```
Ranks the whole tree against a need and prints a grouped context pack: the
modules to read, the protocol objects involved, the prose that specifies them,
what independently checks them, and the metric families that measure them. Every
line cites a path.

```bash
python tools/bbgraph.py node frame
```
One module: its doc comment, cfg gate, size, dependency stratum, what it pulls
in, **what depends on it**, the schemas it declares, and whether anything
independently checks those schemas.

```bash
python tools/bbgraph.py dag
```
Dependency strata and load-bearing rank. Read this before changing anything:
`protocol` is reached by 29 of 33 modules, `world` by 23.

```bash
python tools/bbgraph.py schema
```
The protocol surface. 58 objects, 42 with independent vectors, 16 without.

Stdlib Python only. No network, no build, no `cargo` required.

## Three things that will cost you an hour if you skip them

**1. Most of this crate is not in a default build.** 18 of 33 modules sit behind
`cfg(feature = "protocol-research")`, two of those also behind `cfg(windows)`.
`node <name>` prints the gate. If you are about to run:

```bash
cargo test --features protocol-research
```

**2. `README.md` is not the source of truth, and neither is `index/`.** The
source tree is. `index/` is generated by `python tools/bbindex.py`; never
hand-edit it. If you change `src/`, `docs/`, or `tools/`, regenerate and commit
the diff.

**3. A readable `#bb.metric.*` name is not authority.** It resolves through
`docs/metrics/registry.tsv` to a full SHA-256 definition tag, and the tag is the
authority. The same rule holds for every `#bb.*` tag in this repo: a truncated
digest is display-only. `docs/PROTOCOL.md` is explicit that a digest commits to
bytes and does not prove the bytes are a valid world, frame, or transition.

## Before you commit

```bash
python tools/bbgraph.py gates
python tools/bbgraph.py selftest
```

`gates` runs three accounting checks and a staleness check; `selftest` runs 32
recorded expectations about what the index should answer. Both exit non-zero on
failure.

If `selftest` fails, decide which happened. A ranking change you did not intend
is a bug. A source change that legitimately moves an answer is not — update
`tools/bbselftest.json` in the same commit and say why.

If `gates` reports staleness, the index has **already been regenerated** by that
run. Commit the diff.

## What the index will not tell you

It is parsed from source text. It does not build, run, or verify anything. A
module appearing here is not evidence that its tests pass. Dependency edges are
textual, so a `crate::foo` inside a comment still counts. Sixteen protocol
objects have no independent vectors — they are unchecked, not wrong.

Full detail: `AGENTS.md`.

# THREAT-D0: pre-profile adversary and claim envelope v1

This document resolves `PS-066:THREAT-D0@base` as **BOUNDED**. It enumerates attacker powers,
protected public properties, assumption slots, loss conditions, candidate mitigations, and
unquantified measurement slots **before** `CRYPTO-D1`, `CONSENSUS-D1`, `GOVERNANCE-D1`, or
`PROFILE-SCOPE-D0` select concrete cryptographic primitives, consensus rules, or network bounds.

No entry below selects a cryptographic primitive, consensus mechanism, governance authority, or
production threshold. Every quantitative slot marked `OPEN (UNQUANTIFIED)` remains explicitly open
and must be filled with measured `COST-1` / `BOUNDS-1` evidence in `THREAT-1` before any network
profile can be admitted.

## Non-claims

This pre-profile envelope is **not** a quantitative adversary model (`THREAT-1`), does not prove
security against any listed attacker, does not select primitives or consensus mechanisms, and does
not license any public Layer-1 or production-value claim.
